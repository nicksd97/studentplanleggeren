# Brand favicon (replace stock Next.js icon)

Date: 2026-10-28
Branch: `cursor/favicon-3e8d`

## Goal

`/favicon.ico` on production (`studentplanleggeren.vercel.app`) was still the default Next.js 25931-byte icon. Website Maintenance asked to replace Vercel/Next stock favicons with the Studentplanlegger logo. No product or feature changes.

## What was already brand

- `public/favicon.png` already matched `public/images/brand/Studentplanlegger_Logo.png` (same file). Kept as-is.
- `app/layout.tsx` already pointed `icons.icon` / `icons.apple` at `/favicon.png`. Browsers still request `/favicon.ico` first.

## Changes

| File | Action |
|---|---|
| `app/favicon.ico` | Replaced stock Next.js ICO with a 16×16 + 32×32 brand ICO (from the supplied favicon assets) |
| `app/icon.png` | 32×32 brand PNG (Next.js file convention) |
| `app/apple-icon.png` | 180×180 brand PNG (Next.js file convention) |
| `public/apple-touch-icon.png` | Same 180×180, well-known path |
| `public/favicon.png` | Unchanged |
| `app/layout.tsx` | `icons` now lists `/favicon.ico`, `/favicon.png`, and the 180×180 apple icon |

## Out of scope

Copy, routes, checkout, analytics, emails, and planner PDFs.
